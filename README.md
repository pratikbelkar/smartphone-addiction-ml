# Smartphone Addiction Risk Prediction — runnable mini project

A complete educational classification demo. **The included 1,500-row CSV is synthetic**, generated by `generate_dataset.py`. Its labels come from a disclosed formula with random noise. High accuracy on this data only shows how well a model recovers that artificial rule. Do not present it as evidence of real smartphone addiction or a clinical test.

## Files

- `data/smartphone_usage_synthetic.csv`: included dataset, 1,500 rows
- `generate_dataset.py`: reproducibly rebuild the dataset (seed 42)
- `train.py`: split, train three models, select by validation macro F1, test once, save artifacts
- `app.py`: Streamlit form with predicted category and synthetic-data class probabilities
- `artifacts/`: generated after training (`model.joblib`, `metadata.json`, `metrics.json`)

## Run on macOS (Terminal or VS Code)

```bash
cd smartphone_addiction_ml
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python train.py
python -m streamlit run app.py
```

Open the local URL printed by Streamlit, usually http://localhost:8501. The CSV is already included. To recreate it, run `python generate_dataset.py` before training.

## Run on Windows PowerShell

```powershell
cd smartphone_addiction_ml
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python train.py
python -m streamlit run app.py
```

If PowerShell blocks activation, use `.venv\Scripts\python.exe -m pip install -r requirements.txt`, then `.venv\Scripts\python.exe train.py`, and `.venv\Scripts\python.exe -m streamlit run app.py`.

## What training does

1. Reads the included CSV and validates its seven numerical features plus `risk_level`.
2. Makes a stratified 80/20 development/test split; the development part is split 75/25 for training/validation. Final proportions: 60% train, 20% validation, 20% test.
3. Compares Logistic Regression, Decision Tree and Random Forest on validation macro F1.
4. Refits the chosen pipeline on development rows and evaluates the held-out test set once.
5. Writes the saved pipeline, class labels, classification report, and confusion matrix to `artifacts/`.

The script handles missing numerical values with a median imputer fitted on training data. Only load `model.joblib` files you created or trust. Re-run `train.py` locally if your scikit-learn version differs from the version that saved a model.

## Example inputs

Daily screen time 9 h, social media 4 h, gaming 1 h, phone checks 170, night use 120 min, sleep 5 h, study 2 h. The app returns a predicted class and class probabilities; exact values depend on the fitted model.

## If you want a real research claim

Collect consented responses and define `risk_level` using an independently administered, appropriately validated questionnaire. Replace `data/smartphone_usage_synthetic.csv` with a CSV that uses the same column names, inspect label balance, and rerun training. Adapt the features and app together if your real survey has different fields. Do not infer addiction from screen time alone.
